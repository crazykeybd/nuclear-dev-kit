# 软件理论模型报告（p4-theoretical-model-report）
## 用途
生成软件《理论模型报告》：结合理论基础、实验数据和工程经验，开发能反映产品对象在特定参数环境中行为的物理模型，研究数值算法，评估模型适用范围、边界条件及建议参数赋值。注意：理论模型报告角度对外可提供。

母版：过程资产库V5.0/04_软件设计/04-01.0【模板】中文软件名+英文软件名+空格+二位版本号+理论模型报告.docx

## 章节结构
摘要 → 缩略语表 → 主要符号表 → 中英文术语对照表 → 参考文献 → 1 前言（1.1 目的 / 1.2 综述）→ 2 软件（系统）概述 → 3 软件物理模型：

3.1 基本守恒方程组（例：XXXX 守恒方程）
3.2 辅助模型及本构关系式（例：XXXX 关系式）
3.3 XXXX 模型（专项模型，例：XXXX 关系式）
### → 4 总结
## 表格字段
表 2-1 本次计算中应用的计算机程序；表 2-2 计算输入参数及来源
封面：版本/日期/状态/编写人/校核人/审核人/批准人/修改—说明；项目名称、文件编码、外部编码、项目代码、子项号、文件类型、设计阶段、参考文件编码、REV.、文件种类（A/B/C，示例勾选 C:New）、部门内部编码、关键词；签署页（批准/审核/校核/编写/会签人）
## 填写要点
公式需编号且采用"章节-序号"格式（如（3-1）），公式居中。
正文核心是三大类物理模型：基本守恒方程组、辅助模型/本构关系式、专项模型。
末尾总结需说明模型数值算法研究与适用范围、边界条件、建议参数赋值。
## 生成方法
复制母版 DOCX 后用 python-docx 填充章节与公式；无母版时按上述结构新建。
