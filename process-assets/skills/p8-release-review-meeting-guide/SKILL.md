# 组织软件发布评审会的指引（p8-release-review-meeting-guide）
## 用途
规范软件发布评审会的组织流程（会前、会中、会后），6 页指引 PDF。

母版：过程资产库V5.0/08_软件发布/08-0发布指引/2-【指引】组织软件发布评审会的指引.pdf

## 关键点
## 目的
提升评审会规范化，确保软件质量、顺利交付。

参会人员（原则）
评审委员会主任（软件所总工）、软件负责人（A/B角）、需求/测试/验证人员、数据管理员、室主任、质量管理人员（室级+所级）、系统管理人员及受影响用户；粗体标注者为必须参会。

## 会前准备
明确人员 → 定时间地点（设备齐备）
评审材料：发布评审 PPT 按模板编制并先经室主任及室/所级质量管理员形式审查；会议指南、签到表按模板；外部领导参加需准备桌签
提前 2 个工作日发会议通知（附会议指南+PPT）
## 会议流程
室主任介绍背景 → 评审组长宣布开始并主持 → 软件负责人介绍材料 → 专家提问团队答复 → 组长总结并宣布结论

## 会后
通过 → 所级质量工程师平台审批并跟踪总工环节；团队 1 个工作日内整理意见形成《软件发布评审报告单》并签字
未通过 → 1 个工作日内整理意见、制定方案与时间表，问题解决后再次评审
## 附件一
会议指南模板：含议程安排表（日期/时间/议程/责任人）、与会人员表（评审专家+项目团队代表）。

## 使用方法
作为发布评审会组织指引；需要时输出会前检查清单或生成会议指南。
