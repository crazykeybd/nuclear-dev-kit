# 软件验证与确认（V&V）报告（p7-vv-report）
## 用途
生成软件《验证与确认报告》，记录 V&V 过程与结果（事后记录），章节与大纲一一对应，便于对照填写。

母版：过程资产库V5.0/07_软件验证与确认/07-02.0【模板】中文软件名+英文软件名+空格+二位版本号+验证与确认报告.docx

## 章节结构
封面 → 历史版本/修改记录 → 目录 → 摘要 → 缩略语表 → 主要符号表 → 中英文术语对照表 → 参考文献（GB/T 7714 格式提示）→ 1 前言（1.1 目的；1.2 软件概述；1.3 验证与确认人员：软件负责人/开发人员/验证人员，提示关注验证人员与开发人员的独立性）→ 2 软件验证（2.1 理论解验证；2.2 基准题验证；2.3 同类软件对比验证，均"如有"）→ 3 软件确认（3.1 分离效应实验确认；3.2 整体效应实验确认；另含电厂数据确认、基准题确认，均"如有"）→ 4 敏感性分析（空间网格、时间/燃耗网格、收敛准则等）→ 5 不确定度分析（分与直接测量/间接测量试验数据对比的量）→ 6 总结

## 表格字段
封面信息表：项目名称/文件编码/外部编码/项目代码/子项号/参考文件编码/REV/文件种类（A:Identical/B:Modified/C:New）、关键词、版权声明
历史版本表：版本Rev/日期/编写/校核/审核/批准/修改说明
文件修改记录表：版本/章节/页码/修改范围及依据
签署页：标题/批准/审核/校核/编写/会签
## 填写要点
各验证/确认小节统一子结构：
验证：验证问题描述/算例描述 → 结果对比 → 结论
确认：实验的描述 → 实验的概要 → 软件的建模 → 结果对比 → 结论
确认结果评定说明："与试验数据对比的确认结果如何评定，趋势对比，数值对比"。
章节号带"（如有）"可裁剪。
## 生成方法
复制母版 DOCX 后用 python-docx 填充章节；无母版时按上述结构新建。
