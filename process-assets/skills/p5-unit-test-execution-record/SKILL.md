# 单元测试执行记录表（p5-unit-test-execution-record）
## 用途
生成单元测试执行记录表，按单元模块分组记录测试用例的执行与对比结果。

母版：过程资产库V5.0/05_软件编码实现/05-03【模板】单元测试执行记录表.docx

## 表格字段
表头区：软件名称 | 软件版本 | 采用的单元测试工具
用例区（按单元模块分组，每模块一组）：测试用例编号 | 测试用例名称 | 测试用例描述 | 测试输入数据 | 预期值 | 软件计算值 | 确认
子字段说明：
用例编号 = UnitTest+序号
用例名称 = 软件关键模型、核心模块定义及单元层级划分（示例：锆水反应子模块 / 计算锆水反应 Baker-Just 公式）
描述、输入数据、预期值（含权重等输出）、软件计算值、确认（通过/不通过）
## 填写要点
模块可重复追加；逐项对比预期值与软件计算值，在"确认"列填"通过/不通过"。
## 生成方法
复制母版 DOCX 后用 python-docx 填充/追加行；无母版时按上述字段新建表格。
