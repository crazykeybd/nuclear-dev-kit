# 数据描述文件（p7-data-description-file）
## 用途
为入库/升版的数据编写描述性文件，说明数据物理意义、来源与建模背景。

母版：过程资产库V5.0/07_软件验证与确认/07-04【模板】数据管理/数据入库、升版/06-25【模板】数据名-数据负责人-数据描述文件模板（试行）.docx

## 章节结构
1.0 实验项目背景介绍
2.0 实验台架概述（2.1 整体概述：含回路示意图、物理尺寸；2.2 结构部件及其参数介绍；实验数据必需，可引用参考文献）
3.0 实验设计工况描述（3.1 实验目的：验证/评估何种关键现象；3.2 实验描述：对试验工况的描述）
4.0 数据描述（各属性项物理意义表述）
5.0 建模说明（5.1 建模输入卡概要性说明：何种软件输入卡、近似模拟何种试验/现象、关键假设；5.2 建模输入卡详细说明：示意图、系统主要参数、各模块描述）
6.0 参考文献

## 表格字段
升版跟踪表：版本 | 数据升版原因 | 日期 | 修改页
## 格式要求
小四号；中文宋体、英文 Times New Roman；标点用英文。
参考文献按内部技术报告/法律法规及公司管理程序/外部文献（GB/T 7714-2015，含论文集、期刊、学位论文、专利、国标、报告、报纸、电子资源示例）著录。
## 生成方法
复制母版 DOCX 后用 python-docx 填充章节；无母版时按上述结构新建。
