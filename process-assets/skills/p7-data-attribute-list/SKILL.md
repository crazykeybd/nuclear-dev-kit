# 数据属性清单（p7-data-attribute-list）
## 用途
登记每个数据文件的核心属性元数据，供数据资产管理查询用。

母版：过程资产库V5.0/07_软件验证与确认/07-04【模板】数据管理/数据入库、升版/06-25【模板】数据名-数据负责人-数据属性清单（试行）.xlsx

## 结构
3 个 Sheet（Sheet1 有内容，Sheet2/Sheet3 空白待用）。
列（21 列）：数据类型、项目名称、项目描述、实验名称、数据名称、适用软件、适用堆型、适用专业、评估对象、产生机构、数据来源、特征参数、获取渠道、参考文献、产生机构（重复出现）、数据编号、数据负责人、数据目录、数据版本、入库日期、备注
填写示例（参照填写）
数据类型=运行数据；示例：大亚湾核电厂1号机机组，CPR1000，COCO 软件，适用堆型 CPR1000、专业=物理、评估对象=功率分布/反应性计算、数据来源=电厂月报→M9000 服务器堆芯专业 imodel 建模 或 启动物理试验报告、获取渠道=集团内部数据、数据版本=A。
## 生成方法
用 python-exec（openpyxl）生成 3 Sheet XLSX；无母版时按 21 列建表。
