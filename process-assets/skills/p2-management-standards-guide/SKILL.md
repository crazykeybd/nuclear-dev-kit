# 遵循的管理标准和程序指引（p2-management-standards-guide）
## 用途
为《软件策划报告》第 2.1 节约「项目物项（管理标准、程序、工具）质量管理」提供应遵循的管理标准和程序的清单及查询途径。

母版：过程资产库V5.0/02_软件策划/02-01.1【指引】遵循的管理标准和程序.docx

## 内容要点
应用的管理程序清单共享位置：\\cnt-nas2\SDC\【新】共享文件夹\A管理-007程序资料\1-所内程序
所有管理程序可在**程序管理系统（UDM）**查询：http://udm/#/search_file/supervise_manage_tips
正文以"应用的管理程序清单："为引导语句，无结构化表格。
## 使用方法
编写策划报告 2.1 节时：从上述位置/系统取得项目应遵循的程序清单，逐一列出程序名称；在策划报告中注明清单的最新版本共享位置。需要时用 python-docx 输出一段指引正文。
