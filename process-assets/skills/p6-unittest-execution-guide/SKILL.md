# 软件单元测试执行指引（p6-unittest-execution-guide）
## 用途
提供 2023 年软件单元测试执行指引/要求（软件所宣贯），指导单元测试覆盖率考核、工具选型、用例归档与报告编写。

母版：过程资产库V5.0/06_软件测试/2023年软件单元测试执行指引-20230418.pptx

## 核心要求
考核要求：2023 年安全分析用单元测试覆盖率按 100%（2022 为标准 60%，以设计报告单元数为准）。
执行范围：全新开发软件须对全部模块执行；其他版次须对新增/改动模块执行；历史软件评估生命力决定是否补齐；技转二次开发对新增/改动模型执行；外委软件须在采购技术规范中规定单元测试要求并提供报告；涉及开源代码/开源库的模块也须测；测试对象对照需求/设计报告的模块（最小执行对象）。
工具选型（4+1 工具）
C++ → C++Test、GTEST；Java → JTest、JUnit；Python → PyTest。
C++Test 企业级、覆盖率丰富、自动化打桩；pytest 易上手/参数化/html 报告/jenkins 集成。
不支持工具的项目须手动单元测试（如 FORTRAN、C#）。
## 用例归档
用例及执行记录归档到 SVN，例：svn://192.168.200.102/LD/trunk/code/YYY/YYY_UnitTest。
软件发布前质保平台和数据室测试团队抽查。
## 报告编写
模板从 NAS \\cnt-nas2\SDC\【新】共享文件夹\1.过程资产库\...\06_软件测试 下载。
测试报告中须体现单元测试用例 SVN 路径和记录表。
用例编写分工：专业软件室关注建模/功能完备；数据研究室关注 IT 类（内存泄露、控制参数、边界、性能、兼容性）。
## 使用方法
作为单元测试执行的参考指引；需要时用 ppt_job 生成宣贯 PPT 或按要点输出执行方案。
