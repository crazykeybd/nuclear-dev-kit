# 设计过程评审单（p4-design-review-sheet）
## 用途
生成设计阶段过程评审单（表头 FM-GP-304-E05-01），记录软件设计过程评审的基本信息、结论与整改意见跟踪。

母版：过程资产库V5.0/04_软件设计/04-03【模板】设计过程评审单.docx

## 表格字段
评审级别：□公司级 / □项目级 / 所级（部门级）/ 室级；评审形式：√会议评审 / □文件评审
项目名称、项目代码、编制人、设计阶段（软件研发）、评审日期、批准人、评审组长、参评人员、评审标题、评审内容
评审结论描述 + 勾选：□通过 / □有条件通过 / □不通过 / □其他
评审意见表：序号 | 意见内容 | 建议执行人／建议完成日期 | 执行情况 | 执行描述 | 执行人／日期 | 检查结果 | 检查人／日期
## 填写要点
与 03-03（需求过程评审单）为同一通用"设计评审单"表单的两种用法，字段结构一致。
差异仅在评审内容项：本文评审《理论模型报告》《概要设计报告（如有）》。
示例：中广核堆芯设计软件 / 某系统 XX 软件设计过程评审，项目代码 R-2015ZBREC008（产品线与项目线同时进行时含 R-XXXXXX）。
评审意见须跟踪到"执行情况/执行描述/执行人/检查结果/检查人"闭环。
## 生成方法
复制母版 DOCX 后用 python-docx 填表；无母版时按上述字段新建单表表单。
