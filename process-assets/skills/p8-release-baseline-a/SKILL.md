# 软件发布基线配置表-安全A类（p8-release-baseline-A）
## 用途
安全 A 类软件发布前生成《软件发布基线配置表》，记录发布基线的配置管理项清单及其编码/版本，经质量工程师、软件负责人签字确认。

母版：过程资产库V5.0/08_软件发布/08-01.1【模板】软件发布基线配置表-安全A类.xlsx

## 结构
单工作表 Sheet1：软件元信息区 + 「基线组成列表」明细表 + 签字区。

## 字段/列
头部：软件名称、软件代号、基线版本、SVN号、时间、系统管理员[签字]
明细表：配置管理项名称、编码、版本（阶段：软件策划 / 软件需求分析 / 软件设计 / 软件编码 / 软件测试 / 软件验证与确认）
底部：质量工程师、软件负责人（签字）
## 填写要点
基线组成按生命周期阶段（策划、需求、设计、编码、测试、验证与确认）分组，每个成果物填编码+版本。
示例版本均为 A；V&V 报告示例版本 D。
示例软件：CYCAS（三维氢气安全分析软件）v1.0.0。
## 生成方法
用 python-exec（openpyxl）生成 Sheet1（头部+明细+签字区）。
