# 项目配置管理计划编制指引（p2-config-management-plan-guide）
## 用途
说明《项目配置管理计划》的编制来源与责任角色，供策划报告 4.11 节引用。

母版：过程资产库V5.0/02_软件策划/02-02.1【指引】项目配置管理计划的编制.docx

## 内容要点
《项目配置管理计划》由软件系统管理员提供（模板示例中的系统管理员为"付从"，以实际项目为准）。
无结构化字段或表格，正文仅一句指引。
## 使用方法
在软件策划报告 4.11 配置管理计划中写明：配置管理应详述于《XX项目配置管理计划》，该文件由软件系统管理员提供；并按母版约定由系统管理员维护。需要时可用 python-docx 输出该指引正文。
