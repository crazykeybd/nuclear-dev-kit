# 静态测试缺陷解释表（p6-static-defect-explanation）
## 用途
生成静态测试致命+严重缺陷的逐条解释/说明表，用于证明缺陷可接受或属误判。

母版：过程资产库V5.0/06_软件测试/06-04【模板】静态测试缺陷解释表.docx

## 表格字段
签署栏：编制/审核/批准
检测信息：检测人|时间、文件数|缺陷数、代码总行数|耗时（示例：236 文件、69533 行、1004 缺陷、12min07s）
缺陷汇总：序号|缺陷/漏洞名称|严重等级|数量（示例：S_15_01 变量未初始化使用-致命、S_30_03 空指针解引用-严重、S_19_01 字符串差一错误、S_23_05 外部输入作循环跳出条件、S_06_01 分配内存未释放、S_06_07 可疑内存泄漏、S_26_04 参数类型不兼容）
缺陷详解：序号|缺陷详细信息|备注，详情含缺陷ID与名称、严重等级、文件路径+行号、描述、说明；备注列填反证（如"第192行采用函数对其进行了赋值"表明已初始化）
## 填写要点
逐条对静态工具的致命/严重告警给出合理解释（是否误判或可接受）。
填写者须签名（编制/审核/批准）。
## 生成方法
复制母版 DOCX 后用 python-docx 填充行；无母版时按上述字段新建表格。
