# 软件用户手册（p5-user-manual）
## 用途
生成压水堆核电厂计算类软件的《用户手册》，命名规则：中文软件名+英文软件名+空格+二位版本号+用户手册。

母版：过程资产库V5.0/05_软件编码实现/05-01.0【模板】中文软件名+英文软件名+空格+二位版本号+用户手册.docx

## 章节结构
封面 → 历史版本记录/文件修改记录 → 目录、表目录、图目录 → 摘要+关键词 → 缩略语表 → 主要符号表 → 中英文术语对照表 → 参考文献 → 1 前言（1.1 目的、1.2 软件（系统）概述）→ 2 软件运行环境（2.1 硬件、2.2 软件）→ 3 使用过程（3.1 软件安装与目录、3.2 软件运行说明、3.3 软件输入文件（界面）说明、3.4 软件输出文件（界面）说明）→ 4 示例（如有）

## 表格字段
封面表：项目名称、文件编码 Doc. No、外部编码 External No、标题、项目代码 Project NO、子项号 Sub-Item NO、文件类型 Document Type、设计阶段 Engineering Phase、参考文件编码 + Document Category（A:Identical/B:Modified/C:New）、部门内部编码 Internal Code、关键词 Key Words
修订记录表：版本/日期/状态/编写/校核/审核/批准/修改说明
签署页：批准/审核/校核/编写/会签人
正文表：表1 示例表、图1 示例图
## 填写要点
每节有"说明："引导语与 {例如：…} 示例（如 CGN 自研 GINKGO、COTTON 等）。
人机界面内容多时另起用户说明书；对外示例须脱密。
符号表、字体格式（宋体三号加粗等）按规范；导出/文件名须按命名规则。
## 生成方法
复制母版 DOCX 后用 python-docx 填充章节与示例；无母版时按上述结构新建。
