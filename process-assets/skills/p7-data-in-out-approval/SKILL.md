# 数据入库、升版审批单（p7-data-in-out-approval）
## 用途
数据入库或升版前的审批记录单。

母版：过程资产库V5.0/07_软件验证与确认/07-04【模板】数据管理/数据入库、升版/06-25【模板】数据名-数据负责人-数据入库、升版审批单（试行）.docx

表格字段（单表表单）
数据流程审批类型：□数据入库 / □数据升版
数据基本信息：数据编号（提示"如有：准备申请材料找管理员申请"）、数据类型、数据名称
数据负责人信息：部门、员工号、姓名、联系电话
## 审批步骤
形式审核意见（数据管理员意见，签名+日期）→ 技术审核意见（专业负责人意见，签名+日期）
底部记录：数据管理员 / 数据入库/升版日期
## 生成方法
复制母版 DOCX 后用 python-docx 填表；无母版时按上述字段新建表单。
