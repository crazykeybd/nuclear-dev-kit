# 软件发布评审-安全A类（p8-release-review-deck-A）

生成安全 A 类软件发布评审汇报 PPT（19 页模板）。

母版：过程资产库V5.0/08_软件发布/08-02.1【模板】软件发布评审-安全A类.pptx

## 页结构与要点
封面（XXX软件发布评审，软件负责人）
## 目录
3-4. 01 软件概述（软件类型：安全A/B类、非安管理/设计类）
5-6. 02 开发过程：开发计划表（计划时间|实际时间|里程碑阶段|完成情况，含策划/需求/编码/测试/发布）+ 人力资源计划表
需求情况（数量、完成情况、需求矩阵表）
软件设计情况（模块划分图）
测试情况：单元/集成/系统测试、静态扫描、安全测试（可让测试人员填写）
软件验证情况 / 软件确认情况
代码基线（SVN）+ 文档基线：表「开发阶段|成果物名称|成果编码|版本」（策划/需求/设计/编码实现/软件测试/验证与确认各阶段成果物）
遗留项 + 软件部署 + 软件培训 + 后期维护（示例环境：IDEA/JAVA/CUD 框架、Linux RedHat 7.6/8.3、MySQL、中台部署）
公共代码库1 / 公共代码库2（可复用代码说明）
知识产权情况分析：表「知识产权风险点|详细内容|解决措施」（示例含专利技术 GPL 开源库等风险与规避/替换措施）
15-16. 03 软件演示（使用简述，可截图/照片）
17-18. 04 专项评审结论（四选一勾选：合格通过 / 基本合格略改 / 不合格重新评审 / 仅提问题不定结论）
谢谢（严·慎·细·实）
