# 软件发布评审-非安管理类（p8-release-review-deck-nonsafety）
## 用途
生成非安（非安全管理类）软件发布评审汇报 PPT（16 页模板，比 A 类精简）。

母版：过程资产库V5.0/08_软件发布/08-02.4【模板】软件发布评审-非安管理类.pptx

## 页结构与要点
封面（XXX软件发布评审）
## 目录
3-4. 01 软件概述（软件类型四选一）
5-6. 02 开发过程：开发计划表（计划时间|实际时间|里程碑阶段|完成情况）+ 人力资源
需求情况（数量、完成、需求矩阵表）
测试情况：单元/集成/系统测试、静态扫描、安全测试（无 A 类的"软件验证/确认"独立页）
代码基线（SVN）+ 文档基线：表「开发阶段|成果物名称|成果编码|版本」
遗留项 + 软件部署 + 软件培训 + 后期维护
公共代码库1 / 公共代码库2
12-13. 03 软件演示（使用简述）
14-15. 04 专项评审结论（四选一勾选）
谢谢（严·慎·细·实）
## 与 A 类的差异
A 类多「软件设计情况」「软件验证/确认情况」两页（19 页 vs 16 页）；非安类无 V&V 相关页面。
其余（代码基线表、知识产权、评审结论勾选、部署/培训/维护示例）内容相同。
## 生成方法
用 ppt_job 生成 PPTX，按上述页结构与表格填写真实数据；无真实数据时保留占位。
