# 数据使用申请表（p7-data-use-application）
## 用途
数据使用前申请与审批，含保密承诺。

母版：过程资产库V5.0/07_软件验证与确认/07-04【模板】数据管理/数据使用/06-25【模板】数据名-数据负责人-数据使用申请表（试行）.docx

表格字段（单表表单）
部门、申请人员工号、申请人姓名、申请日期、联系电话
申请使用数据编号、数据名称
数据使用场景及需求、数据使用的必要性说明
数据使用范围（勾选：个人使用 / 项目使用 / 其它）
## 审批/签署流程
申请人所在部门意见（负责人签名+日期）→ 数据管理部门意见 → 数据负责人意见 → 专业负责人意见（各留签名+日期）
底部：数据管理员、提供数据日期
## 承诺条款
本人承诺严格控制数据使用范围，数据使用完成后销毁所有数据文件拷贝，若因违反带来违纪问题由本人承担；申请人签名（工号+姓名）+日期
## 生成方法
复制母版 DOCX 后用 python-docx 填表；无母版时按上述字段新建表单。
