# 物理模型需求：核工程领域参考

> 参考性材料，不替代适用标准、法规解释或持证人员判断；不参与门禁判定。

## 写什么

把"物理模型"写成可验证需求时，至少覆盖以下内容；缺失项进入 `open_items`，不要写 `TBD`。

| 主题 | 需求应写明的量 |
|---|---|
| 守恒 | 质量/动量/能量/中子数守恒关系、守恒量单位、允许误差与适用条件 |
| 本构/关联式 | 状态方程、截面/物性来源、本构关系、参数范围与外推禁令 |
| 初始/边界条件 | 边界类型、数值、单位、坐标系、符号约定、时间依赖 |
| 适用范围 | 几何、材料、能谱、压力/温度/燃耗区间，明确外推限制 |
| 假设/限制 | 稳态/瞬态、均匀/非均匀、各向同性/各向异性、单/多相等 |
| 数值指标 | 目标精度、收敛容差、守恒残差、网格/时间步敏感性要求 |

## 中子学

- 临界/次临界系统：说明keff 目标、反应性、中子通量与功率分布的归一化方式。
- 输运/扩散模型：说明能群结构、散射各向异性阶数、边界条件（真空/反射/周期）、差分/节点/特征线或 Monte Carlo 方法。
- 燃耗：说明燃耗链、核素清单、截面库与自屏蔽处理、时间步策略、单位（MWd/tU）、初始富集度。

## 热工水力与 CFD

- 说明相模型（单相/两相）、湍流/层流、传热与摩擦关联式、可压缩/不可压缩假设。
- 写清压力、温度、焓、质量流量、空泡份额等接口单位；坐标系与符号约定必须一致。
- 多物理耦合：给出耦合变量、映射方式、时间步同步与数据守恒要求。

## 辐射屏蔽与剂量

- 说明源项能谱与归一化、几何/材料、屏蔽量（注量率、剂量率）、蒙特卡罗方差控制方法与计数统计要求。

## 验收写法示例

不要写"精度良好"。写：在给定基准题 X 的指定测点，keff 与参考值偏差 ≤ 指定阈值，功率分布最大相对偏差 ≤ 指定阈值，且守恒残差低于指定阈值；阈值由安全等级和基准不确定度推导并记录来源。
