# 配置与数据冻结：核工程领域参考

> 参考性材料；不参与门禁判定。

## 发布冻结清单

- 源码 revision 与实现阶段一致，工作区干净。
- 语义版本、发布范围路径、构建配置（编译器、flags、依赖、MPI、OS、容器）。
- 核数据/截面库版本、加工链、能群与温度点、校验和。
- SBOM 格式、路径与证据；漏洞/许可证/支持状态说明。
- 复现与回滚证据均为 `passed`；已知限制与残余风险汇总。

## 长期归档

- 保存源码、核数据、构建脚本、输入算例、基准来源、证据与批准记录。
- 记录外部 URL 的获取日期与本地副本校验和，避免链接失效导致不可复现。
- 对敏感或受控数据按项目策略分类与访问控制，不得随公共包外发。

## 回滚

- 回滚程序必须实际演练，验证旧版本恢复、数据兼容与责任人可执行性。
- 若数据版本回滚会影响结果，必须在已知限制中说明，并禁止把旧结果等同于新配置下的结论。

## 与门禁的关系

发布门禁要求全部 REQ 与 MOD 由 `REL --contains-->` 覆盖，SBOM/复现/回滚引用通过证据。本文件只指导冻结什么，不改变判定规则。
