# 可复现构建：核工程领域参考

> 参考性材料；不参与门禁判定。

## 冻结项

发布与实现阶段应冻结并记录：

- 编译器名称、版本与构建 flags（优化级别、浮点模型、预处理宏）。
- 依赖及版本：MPI/线性代数库、HDF5/NetCDF、核数据加工工具。
- 容器镜像摘要（若使用容器）、操作系统与内核版本。
- 源码 revision、工作区 dirty 状态、核数据版本与校验和。

## 可复现检查

- 在清洁环境按文档重建，比对产物 SHA-256；差异必须解释，不能忽略。
- 浮点差异在容差内可判定通过，但容差必须来自验收准则，不能事后挑宽。
- 构建脚本必须可在受控环境中重跑；不能依赖个人机器上的临时环境变量。

## 与门禁的关系

- `implementation.build_evidence_ids` 只引用结果为 `passed` 的证据。
- `release.reproducibility` 与 `rollback` 必须 `verified=true`，并引用真实通过证据。
- 本文件仅指导如何产生证据，不改变门禁规则；门禁仍由 `nuclearlib.py` 判定。
