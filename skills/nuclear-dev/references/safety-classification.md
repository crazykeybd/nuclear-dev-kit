# 安全分级与 V&V 等级：核工程领域参考

> 参考性材料；不参与门禁判定。分级必须由具备权限的人员依据项目适用法规与标准确认。

## 分级从后果出发

安全分级回答"软件失效会造成什么后果"，不是按软件规模或复杂度随意指定：

1. 识别软件所属系统/功能及其安全角色（保护、控制、监测、分析、支持）。
2. 分析失效后果：是否影响反应堆停堆、专设安全设施、辐射防护、临界安全。
3. 按适用标准确定安全类别/等级（如 IEC 60880 的 A 类、IEC 62138 的 B/C 类，或项目自定义分级）。
4. 记录分级依据、排除项与待确认边界；监管解释问题标记为需要专业人员判断。

## V&V 等级

V&V 等级由软件风险、物理模型复杂度、失效后果和独立 V&V 要求共同决定：

- 定义 `levels`（等级名称与判据）与 `vv_basis`（为什么是这个等级）。
- 说明代码验证、解的验证、确认的方法组合，以及各方法要达到的证据强度。
- 独立 V&V 必须启用：执行者、审核者、最终批准人的独立性从策划阶段设计。

## 工具鉴定

工具按对产品的影响分级鉴定（常见 T1/T2/T3 分类思想：T1 直接产出产品、T2 可能引入错误但不直接产出、T3 辅助工具）。记录：

- 工具名称、版本、用途、鉴定状态、依据、限制。
- 未完成鉴定写 `pending` 会被门禁阻断；不能把"常用"当"已鉴定"。

## 开放项纪律

未知或待确认的分级、标准适用性、人员资格必须进入 `open_items`；只有真实 `closed` 才解除阻断，`accepted` 仍阻断。
