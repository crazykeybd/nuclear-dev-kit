# HPC 实现：核工程领域参考

> 参考性材料；不参与门禁判定。

## 语言与数据结构

- 传统求解器常见 Fortran/C++，现代实现可能使用 Rust/Python 胶水层；实现记录必须写清语言与版本。
- 稀疏矩阵：CSR/CSC/ELL、块结构、矩阵自由(matrix-free)方法；说明存储格式与内存估算。
- 网格/截面库：数据结构要支持材料/温度/燃耗点索引；索引键与单位必须与需求一致。
- 并行：MPI 通信域、halo 区、线程/OpenMP、GPU 内核与主机内存传输。

## 数值健壮性

- 检查除零、负截面、非物理温度/压力、NaN/Inf、迭代发散等异常路径。
- 编译警告、静态分析告警、未定义行为（UBSan/ASan）结果必须保留，不能只登记"成功"片段。
- 浮点结果受优化级别、快速数学、归约顺序影响；构建 flags 必须冻结。

## 实现与设计一致

- 每个 MOD 的 `design_ids`、`entrypoints`、`paths` 必须对应真实源码与入口。
- 偏离设计的实现必须先更新设计项与追溯，不得在代码中暗改物理含义。

## 证据

- 构建证据：干净构建命令、编译器/依赖版本、退出码、日志。
- 静态分析证据：工具、配置、告警清单及处置。
- 单元测试证据：覆盖函数/接口/异常路径的结果；失败证据保留并登记。
