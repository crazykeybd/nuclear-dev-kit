# 测试模式：核工程领域参考

> 参考性材料；不参与门禁判定。

## 三级测试

- **单元测试**：函数、数据结构、物性接口、边界处理、错误路径。
- **模型级测试**：方程离散、守恒、对称性、极限行为、网格/时间步影响。
- **系统级测试**：完整场景与回归基线，记录 OS、编译器、容器、源码 revision、输入与退出码。

## 四类关注点

- **守恒**：质量、动量、能量、中子数、反应性等不变量与残差容差。
- **边界**：真空/反射/周期边界、材料界面、相界面、极端输入。
- **负向**：非法输入、发散算例、异常路径、数值越界；必须保留失败结果并登记缺陷。
- **回归**：基线产物摘要与结果；基线变化必须显式审批，不得自动覆盖。

## 制造解方法（MMS）

MMS 通过构造已知解析解并代入 PDE 生成源项，验证离散实现是否达到理论收敛阶。设计、测试与 V&V 均可引用；报告应包含网格序列、误差范数、拟合阶与理论阶比较。

## 测试矩阵要素

每个 TEST 项写清：等级、关注点、模块 ID、需求 ID、输入、预期、容差、实际、结果、证据 ID、缺陷。不得只运行成功子集；失败必须进入缺陷与开放项。

## 证据纪律

结果为 `passed` 才能满足门禁；失败证据是有价值的诊断记录，不能改写为通过。同一路径不能重复登记；内容变化后必须重新登记新证据。
